# Svmemo

给中文母语者用的瑞典语背单词网站：间隔重复 + 拼写。产品说明见 [SPEC.md](./SPEC.md)。

线上：https://leonahub.github.io/svmemo/

## 现在有什么

- 词库约 4999 词：词频第 1–100 组（#1–5000）：`src/data/lists/`
- Dexie 本地进度：计划、FSRS 卡片、收藏 / 已掌握、日历、备份
- 今日：到期拼写 + 每 7 个新词先看卡片再拼写
- 点「到期复习」可看已学词还要几天；加练：单词本拼写、例句填空
- 可安装到手机主屏幕（PWA），离线打开已缓存的词库；进度仍在本机浏览器里

## 手机

1. 用 **Safari** 打开上面的网址（不要用微信内置浏览器）
2. 点分享 → **添加到主屏幕**
3. 电脑和手机进度不同步：出门前在电脑上「复制进度 / 导出备份」，到手机上「粘贴导入 / 导入备份」

## 本地运行

```bash
npm install
npm run dev
```

打开后先看「今日」，点「开始背单词」。数据在**当前浏览器**的 IndexedDB 里，Cursor 预览、电脑 Chrome 和手机 Safari 各存一份。换设备时用「复制进度 / 粘贴导入」，或「导出备份 / 导入备份」。刷新会把词库更新到最新版本，学习进度仍留在本地。
