# Svmemo

给中文母语者用的瑞典语背单词网站：间隔重复 + 拼写。产品说明见 [SPEC.md](./SPEC.md)。

## 现在有什么

- 自选 B1 词表（约 641 词）：`src/data/custom-words.ts`
- Dexie 本地进度：计划、FSRS 卡片、收藏 / 已掌握、日历、备份
- 今日：到期拼写 + 每 7 个新词先看卡片再拼写
- 点「到期复习」可看已学词还要几天；加练：单词本拼写、例句填空

## 本地运行

```bash
npm install
npm run dev
```

打开后先看「今日」，点「开始背单词」。数据在**当前浏览器**的 IndexedDB 里，Cursor 预览和 Chrome 各存一份、互不同步。换浏览器时用「复制进度 / 粘贴导入」，或「导出备份 / 导入备份」。刷新会把词库更新到最新版本，学习进度仍留在本地。
